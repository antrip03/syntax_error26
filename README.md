# FinSeries-RLVR (backend)

A small open LLM (Qwen2.5-1.5B-Instruct, LoRA) trained with SFT + GRPO and **programmatic verifiable rewards** to reason over
financial return series. We compare a flat chain-of-thought control with two temporal-abstraction scaffolds (`chunk` = fixed-span
chunk summaries, `event` = verified regime segments). The model **analyses a given series; it never predicts the future.**

Every reasoning step is one parseable line `S<k>: <op>(<args>) = <value>`. A deterministic checker recomputes each line from the
series, which gives the process reward, the step-validity metric, error-propagation analysis, and (in the API) green/red steps.

## Toolkits (all four are used; see `docs/TOOLKIT_USAGE.md` for evidence)
SGLang (serving/eval/sampling) | CuratorKIT (curation pipeline with our verifier + pass-rate gates) | AlignTune (SFT + GRPO with our
reward callables) | AuditKit (scores every reported run with our verifier as scorers).

## Results
See `docs/results/summary.md` (generated by `python -m finseries.eval.report`) and `docs/PROGRESS.md` for the SFT recipe search.

## Run
```
pip install -e . -r requirements-data.txt
python scripts/prepare_data.py           # once (internet): real prices -> data_prepared/ (upload as a Kaggle Dataset)
python scripts/make_tasks.py             # task splits + manifest -> artifacts/tasks/
python scripts/make_sft_extra.py         # extra SFT-only tasks
python -m pytest                         # CPU tests (gold traces, splits, rewards, adversarial probes, AuditKit/CuratorKIT, API)
# Kaggle (T4): notebooks/*/ are thin launchers around scripts/m4_sft.py, scripts/m5_curate.py, scripts/m5_grpo.py
# Modal (A100) for fast SFT experiments: python -m modal run --detach scripts/modal_app.py::detached --variant e5 --arm chunk
uvicorn finseries.serve.api:app          # backend for the UI (needs an SGLang server: finseries/serve/launch_sglang.sh)
```

## Layout
`finseries/verifiers` op registry + step checker (single source of truth) | `finseries/scaffolds` flat / chunk / event |
`finseries/tasks` families, gold answers, adversarial probes | `finseries/rewards` outcome / process / format / consistency / length |
`finseries/adapters` CuratorKIT, AuditKit, SGLang wrappers | `finseries/train` GRPO driver | `finseries/eval` runner, metrics, report |
`finseries/serve` SGLang launcher and FastAPI app | `configs/` yaml | `docs/` plan, progress, toolkit evidence.
